# Aftermath skills

The Aftermath skill set previously vendored here (`skills/aftermath-perpetuals/`)
was the **v1-era** copy. It documented the retired v1 API host and predates
`aftermath-api` v3.0.0.

It has been replaced by the current official skills, vendored verbatim at:

    AFTERMATH_SKILLS_REF/

with the exact upstream commit recorded in `AFTERMATH_SKILLS_REF/PINNED.md` and
the known-wrong URLs catalogued in `AFTERMATH_SKILLS_REF/README-DELTA.md`.

Nothing in the codebase imported the old directory, so removing it changes no
behaviour.
